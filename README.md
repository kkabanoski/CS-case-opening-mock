Projekt tworzę od zera przy użyciu HTML, CSS, JavaScript. Jest to projekt edukacyjny, na którym ćwiczę pracę z DOM, eventami, tablicami, obiektami, losowością oraz animacjiami.

## Aktualnie zrobione

* podstawowa struktura strony
* podstawowe ui
* karta skrzynki
* lista skinów przechowywana w tablicy obietków
* podział skinów na rzadkości
* losowanie rzadkości 
* reakcja na kliknięcie 
* "animacja otwierania"

## Następne kroki

* połączenie wylosowanej rzadkości z konkretnym skinem
* losowanie skina z wybranej rzadkości
* ulepszenie animacji otwierania
* ekwipunek zebranych skinów
* dopracowanie wyglądu 

## Technologie

HTML CSS JS

## Status

w trakcie tworzenia, aktualnie działa losowanie rzadkości, ale nie wybiera jeszcze konkretnego skina

## Cel projektu

Celem projektu jest nauka JavaScript i tworzenie interaktywnych stron/aplikacji internetowych oraz zrozumienie tego jak działają zdarzenia losowe w aplikacjach.
